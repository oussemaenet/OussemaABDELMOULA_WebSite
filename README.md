# OussemaABDELMOULA_WebSite

## Oussema ABDELMOULA - Personal Website

Ce projet est un site web personnel développé pour présenter mon profil, mes projets et mes compétences dans les domaines des télécommunications, de la cybersécurité, de la data science et du data engineering.  
Le site est conçu pour être simple, moderne et responsive.

---

## Fonctionnalités principales

- Page d’accueil avec une présentation personnelle.  
- Section **À propos** présentant mon parcours académique et professionnel.  
- Section **Projets** détaillant les projets réalisés.  
- Section **Compétences** listant mes compétences techniques et transversales.  
- Formulaire de **contact** intégré.  
- Design responsive adapté aux différents formats d’écran.
